# Project rules

- Keep the proof of concept simple; use no paid services, runtime third-party API calls, accounts, or secrets.
- Keep project files in this root. Put temporary files and npm cache in `_tmp` and `_npm-cache`.
- Update `README.md` and `PLAN.md` as implementation changes.
- Run the relevant automated tests after each implementation step.
- Explain changes briefly in handoff notes and document limitations honestly.
- Never treat a browser-provided filename or owner token as trusted data.

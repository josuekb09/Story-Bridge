Story Bridge helps African storytellers tell and share stories in their own language and voice while keeping control over naming, audience, publication and withdrawal. The proof of concept keeps original text or recording first, lets a storyteller write a translation or request an AI draft that cannot be saved until it is approved, and records timestamps and SHA-256 fingerprints for available versions. The build used OpenAI Codex to preserve the existing authentication and API rules, stabilize draft/publication and identity race behavior, implement a public storytelling journey, add a server-side translation workflow, and create isolated browser and API evidence. Its peacebuilding contribution is modest and concrete: make room for community memories and different perspectives to travel across languages without taking authorship or consent away from the storyteller. Browser-native speech recognition can propose an editable transcript where supported; it is not an OpenAI API integration. This remains a local proof of concept, not a service for sensitive stories.
